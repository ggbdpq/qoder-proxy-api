## Verification Matrix（能力验证分级）

分级口径——**三种证据不混写**：

- **verified**：真实凭证真机验证过（v0.1 时期的 cloudAgents 链路）。
- **fixture verified**：离线可复现，按证据强度分三档标注——
  `抓包`（真实上游抓包回放，`test/fixtures/gateway/live/`）、
  `参考`（与参考实现差分 golden）、`合成`（合成 fixture + 单测）。
- **experimental**：有实现与单测但真机行为未验证。
- **unverified**：未验证。

## 已知缺口（诚实清单）

- gateway 全链路未真机验证：协议随时可能漂移，`text.sse` 等 fixture
  基于历史抓包。
- gateway 模型目录拉取失败静默兜底，失败原因不上抛（`lastError` 只写
  不读）——可观测性缺口，修复属行为变更，未纳入 v0.2.2。
- `characterization: malformed SSE data leaks raw text into delta` 为
  已知 wart（v0.1 语义），修复属行为变更，characterization 先锁定现状。
- 上游 requestTimeoutMs 在 v0.2.0 前不约束 gateway 认证交换、cloud 侧
  超时误报 UNAVAILABLE——已由 `upstreamTimeout.test.ts` 锁定对齐后的语义（v0.2.0）。
